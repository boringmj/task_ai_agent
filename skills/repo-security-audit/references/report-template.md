## 写法要求

- **证据必须能对上结论。** 写"输入可控"就要指出哪一行把请求参数传了进去;写不出来就降置信度。
- **每条问题独立成节**,不要把几个问题混在一段里。
- **修复建议要可执行**:写"改用参数化查询",不要写"注意安全"。
- **利用链单独成节**,这是用户最看重的部分;没找到能串起来的链就如实写"未发现可串联的完整链路"。
- **区分「读到的」和「推断的」**,推断一律标注。
- 报告用中文;代码、文件名、命令保持原文。
- 涉及真实业务数据的,只写影响面,不要贴真实数据样本。
